# User Status — 유저 상태창

[마리나라] 채팅 속 인물과 장면의 상태를 매 턴 기록해 상태창으로 보여 주는 확장 프로그램

## 무엇을 하나

AI 답변이 끝날 때마다 등장인물마다 기분 · 호감도 · HP 같은 상태와 장면(시간 · 장소)을 뽑아 상태창으로 보여 줘요.
상태창의 모양과 칸은 스킨으로 바꿀 수 있고, 메시지 · 스와이프마다 기록이 남아 지난 턴의 상태도 다시 볼 수 있어요.
지금 상태는 다음 답변을 만들 때 AI에게 같이 보내서, 이야기가 앞뒤로 이어지게 해요.

## 설치

1. 엔진 쪽 준비 (처음 한 번만)
   - 서버 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 넣고 서버를 다시 켜요.
   - Settings → Advanced → Danger Zone에서 **Allow third-party extension imports**를 켜요.
2. 아래 셋 중 편한 방법으로 가져와요.
   - **json 파일 하나로**: `user-status.json`을 받아 Settings → Addons → External Extensions에서 가져와요.
   - **GitHub 저장소 연결로**: GitHub 저장소에서 확장을 받는 관리 도구를 쓰면 이 저장소 주소를 넣어요. `manifest.json`을 찾아 설치해요.
   - **ZIP으로**: Code → Download ZIP으로 받아 **Import Extension File**로 가져와요. 압축을 풀었다면 **Import Extension Folder**로 폴더를 골라도 돼요.
3. 검토 화면에서 **Full page access**를 확인하고 승인해요.
4. 페이지를 새로고침해요.

> `user-status.js`만 따로 가져오면 엔진이 샌드박스 확장으로 등록해서 상태창이 뜨지 않아요.
> json 파일, 저장소 연결, 폴더(ZIP)째 가져오기 중 하나로 가져오세요.

**예전 판에서 올릴 때**

- 먼저 **고급** 탭의 **전체 백업**으로 파일을 하나 받아 두세요.
- 기존 User Status를 끄거나 지운 뒤 새 판을 가져와요. 두 개를 같이 켜 두지 마세요.
- 기록 · 설정 · 스킨은 저장 이름이 그대로라 남아 있어요.

## 쓰는 법

- 최신 AI 메시지 아래에 상태창이 떠요. 상태창의 톱니(설정) 아이콘을 누르면 설정 창이 열려요.
- **상태창 설정** 탭에서 스킨을 고르거나 새로 만들어요.
  - 기본 스킨 5가지가 들어 있어요. 스킨 이름을 누르면 어떤 칸이 나오는지 설명이 펼쳐져요.
  - 스킨은 목록의 **추출**로 파일로 내보내고, **상태창 가져오기**로 불러와요(여러 파일을 한꺼번에 고를 수 있어요).
  - `skin` 폴더에 추가 스킨 7가지가 있어요. 받아서 **상태창 가져오기**로 불러와요.
- 데이터 방식은 둘 중 하나예요.
  - **API 따로 연결(권장)**: 답변과 따로 AI를 한 번 더 불러 값만 받아요. 채팅 본문이 깔끔해요.
  - **채팅 출력**: AI 답변에 값 블록을 같이 쓰게 해서 읽어요.
- 인물이 여럿이면 캐릭터 탭을 눌러 바꿔요. 폰에서는 상태창을 옆으로 길게 밀어도 돼요.
- 값이 틀리면 상태창의 연필(값 수정) 아이콘으로 직접 고치거나, 💬(프롬프트 재생성) 아이콘으로 추가 요청을 적어 다시 만들어요.
- **설정 적용 범위**에서 **해당 채팅 전용**과 **공용** 중 마지막에 누른 쪽을 그 채팅이 따라요.
- **기록** 탭에서 지난 턴의 상태를 보고, 빠진 턴은 **빈 턴 채우기**로 채워요(API 방식에서만).
- 상태창을 메시지 안이 아니라 화면에 떠 있는 창으로 보고 싶으면 **고급** 탭에서 **화면에 띄우기**로 바꿔요.

## 알아 둘 점

- **API 방식은 답변마다 AI를 한 번 더 불러요.** 그만큼 토큰을 더 써요. 설정의 참조 범위(채팅 기록 · 요약 · 로어북 · 캐릭터 카드 · 페르소나)와 히스토리 범위로 보내는 양을 줄일 수 있어요.
- **지금 상태는 다음 답변 프롬프트 맨 끝에 `<user_status>` 블록으로 들어가요.** 프롬프트 보기(AI 답변의 돋보기)에서 확인할 수 있어요. 넣고 싶지 않으면 **현재 상태창 값을 입력 프롬프트에 포함**을 꺼요.
  - 예외: 캐릭터 2명 이상 + 개별 응답 + 스마트 응답 순서인 그룹 채팅의 새 답변은, 프리셋을 쓰면 이 블록이 빠져요.
- 롤플레이(Roleplay) 모드 채팅에서 써요. 대화(Conversation) · 게임(Game) 모드는 지원하지 않아요.
- 설정 · 스킨은 마리나라 서버의 확장 저장소에도 저장돼서 다른 기기에서 이어져요. 창 위치 같은 기기별 화면 상태는 빼고요.
  - 스킨 이름 옆 구름 아이콘을 누르면 그 스킨은 이 기기에만 저장돼요. 목록 아래 **서버 연동 · 모두 켜기 / 모두 끄기**로 한꺼번에 바꿔요.
  - 연동을 끈 스킨은 다른 기기에서도 지워지지 않고 그 기기의 사본으로 남아요. 그때부터는 기기마다 따로 바뀌어요.
- 메시지별 상태 기록은 그 채팅에 저장돼요.

## 안 될 때

| 증상 · 안내 | 원인 |
|---|---|
| 상태창이 안 뜨고 콘솔에 `document is not defined` 또는 `window is not defined` | `.js`로 가져와 샌드박스로 등록됐어요. 지우고 위 설치 안내대로 다시 가져오세요. |
| External Extensions 메뉴가 없어요 | `.env` 설정과 Danger Zone 스위치를 둘 다 켜고 서버를 다시 켜요. |
| `출력 형식을 인식하지 못했습니다` | AI가 정해진 형식으로 답하지 않았어요. **원문 보기**로 실제 답을 확인하고, 상태창의 새로고침 아이콘을 눌러 다시 만들어요. |
| `API 오류 — 상태값을 가져오지 못했습니다` | 연결된 AI가 오류를 냈어요. **출력 결과 보기**에 엔진이 알려 준 이유가 나와요. |
| 확장을 끈 뒤에도 상태창이 남아 있어요 | 페이지를 새로고침해요. |

문제를 알려 줄 때는 브라우저 콘솔에서 `await __usDebug.dump()`를 실행한 결과를 같이 보내 주세요.
